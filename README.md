## 🎮 游戏简介

钻石狂潮是一款经典的冒险解谜类游戏，玩家将扮演一名勇敢的探险家，在危机四伏的遗迹中探索、解谜、打怪，并收集钻石和宝藏，体验一场场惊心动魄的冒险之旅。

## ✨ 游戏特色

- **经典玩法**: 忠实还原原版游戏的核心玩法机制
- **三大世界**: 吴哥窟、巴伐利亚、西藏雪洞三大主题世界
- **丰富敌人**: 5种不同类型的敌人，各具特色AI行为
- **多样道具**: 8种功能各异的道具，帮助玩家克服困难
- **像素风格**: 经典像素艺术风格，怀旧而精美
- **响应式设计**: 支持桌面和移动设备
- **流畅体验**: 60FPS游戏体验，优化的性能表现

## 🕹️ 游戏操作

### 键盘控制
- **WASD** 或 **方向键**: 移动角色
- **空格键**: 使用道具
- **ESC**: 暂停游戏
- **Enter**: 确认/开始

### 触控操作
- **虚拟摇杆**: 控制角色移动
- **道具按钮**: 点击使用对应道具
- **菜单按钮**: 访问游戏菜单

## 🎯 游戏目标

- 在每个关卡中收集所有钻石
- 避开或击败敌人
- 到达关卡出口
- 解锁新的关卡和世界

## 👾 敌人类型

1. **雪猿** (Snow Ape) - 追踪型敌人，会追击玩家
2. **少林弟子** (Shaolin Monk) - 远程攻击，释放飞镖
3. **红蛇** (Red Snake) - 对道具免疫，需要直接击败
4. **毒蜘蛛** (Poison Spider) - 可被环境消灭
5. **萨克斯骑士** (Sax Knight) - Boss敌人

## 🛠️ 道具系统

1. **指南针** - 显示关卡路径提示
2. **锤子** - 破坏石块障碍和攻击敌人
3. **抓钩** - 远程抓取物品
4. **冰冻射线** - 冻结敌人
5. **炸药** - 爆炸攻击
6. **护盾** - 防护一次伤害
7. **速度靴** - 提升移动速度
8. **宝石袋** - 得分加成

## 🏗️ 技术架构

- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **游戏引擎**: HTML5 Canvas 2D API
- **音频**: Web Audio API
- **存储**: localStorage (游戏进度)
- **部署**: GitHub Pages
